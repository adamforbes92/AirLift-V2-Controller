Preset Editor

Each preset stores a front-axle and rear-axle target pressure. Tapping a preset on the Overview tab makes the firmware emit the same 01 16 47 … target broadcast the real handheld sends after selecting a preset, so the manifold treats it identically to a physical preset press. Set both PSI values to 0 to leave a slot empty.

#NameFront PSIRear PSI

Learning Presets…

The controller doesn't transmit which preset number was pressed — only the target pressures. So pick the slot below, press Capture, then press that preset on the physical controller; its target lands in that exact slot (in any order). Repeat for each preset, then hit Save.

Display

Mode

Leave this off for normal use. The ESP32 already rests as a transparent wire — the handheld's original buttons work directly — and only seizes the manifold bus for the brief moment you trigger a preset or corner command from this UI, then hands control straight back. Turn it on as a debugging override to force a pure byte-for-byte relay: all injection and auto air-out are suppressed and our controller never transmits, so you can watch the untouched OEM traffic.

Automatic Air-Out

When ignition switches off (CAN bus silent > 3 s) and Air Out is enabled, the selected preset is replayed for 10 s, then a further 10 s delay elapses before the controller is powered down. With Manual, the controller uses pressure feedback to pulse each axle until it reaches the entered target.

Ignition monitoring via aux input reads a hard-wired ignition signal on the auxiliary input (GPIO 39, HIGH = ignition on) instead of waiting for the CAN bus to fall silent. It reacts instantly, then waits a 10 s buffer once ignition is off before airing out (so a crank or brief stall doesn't dump the bags). Leave off to detect ignition from CAN.

Fob Double Press Actions

Controller boot delay
5.0 s

Only remote-fob commands on Comfort CAN are accepted. Press the same fob button twice within 5 seconds to run its enabled action. The boot delay holds the air-up/down command after a cold wake so the handheld can finish its Preset/Manual handshake first — increase it if you still see a comms error, decrease it for a faster response.

CAN Sleep Thresholds

The handheld is powered down when the vehicle CAN bus goes quiet. "Quiet" means both conditions are true: time since the last frame exceeds the silence timer, AND the live frame rate has dropped below the floor. Either condition alone keeps the controller on.

CAN Source

Powertrain CAN uses the quiet-bus ignition rule. Comfort CAN uses the captured fob-command frame and runs at the Comfort bus bitrate.

CAN Broadcast

When enabled, the firmware transmits an 8-byte frame at ~10 Hz on the ID below. Payload: [0]FL [1]FR [2]RL [3]RR [4]Tank (raw PSI×2), [5]flags (bit0 compOn, bit1 ignOn, bit2 intercept, bit3 passthru, bits4-5 mode), [6]seq, [7]0. Switching this on takes the CAN driver out of listen-only mode — do not enable on a bus you don't own.
